# prj--personal-cloud-platform

Architecture and system design documentation for a self-service Kubernetes platform used to host low-traffic personal/portfolio API services on a single AWS Lightsail VPS.

Documentation-only project: no application code, Terraform, or Helm chart implementation lives here — see [`99_workbook`](../../99_workbook/) or a dedicated implementation repository for that.
